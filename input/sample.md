# Welcome to Kokoro

This is a **test narration** generated entirely on your own laptop. No cloud service, no API key, and no per-character bill.

## How it works

Drop a text or markdown file into the input folder, run the generator, and collect the finished MP3 from the output folder. Paragraphs are separated by a short pause, so blank lines in your script shape the rhythm of the narration.

- Headings are read as short sentences.
- Links like [this one](https://example.com) are read as plain text.

That's it. Enjoy the new voice.
